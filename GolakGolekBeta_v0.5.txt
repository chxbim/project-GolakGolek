================================================================
  KONSEP GAME
================================================================


GolakGolek adalah game simulasi Supermarket Hunting 3D.
Player bergerak di dalam minimarket 3D, mencari dan mengambil
item, lalu submit keranjang (objektif game) di kasir.


----------------------------------------------------------------
  MODE PERMAINAN
----------------------------------------------------------------


TIME ATTACK (TA)
  - Player diberi 8 item target yang ditampilkan dengan list nama barang dari TMPro,
    tergantung mode game
  - Gameplay mencari 1 barang spesifik dalam batasan waktu untuk mode Time Attack (TA)
  - Tujuan: temukan semua item sebelum waktu habis
  - Scoring berbasis kecepatan (waktuSelesai dalam detik)


GOLEK
  - Tidak ada batasan waktu
  - Item ditampilkan dengan NAMA RIDDLE (field: displayName)
    bukan nama asli (field: namaItem)
  - Player harus menebak item dari deskripsi riddle
  - Lebih santai, fokus ke puzzle/tebak-tebakan


KASIR (bukan mode — fitur submit)
  - Saat player masuk zona kasir, muncul UI konfirmasi
  - Player confirm → CartSystem POST ke API
  - Tidak ada kalkulasi harga untuk player
  - Kasir murni untuk submit sesi game

----------------------------------------------------------------
  SessionCache.cs  [SELESAI & SIAP PAKAI — static class]
----------------------------------------------------------------
Static class — tidak perlu attach ke GameObject.
Persistent login session via Unity PlayerPrefs.


Storage keys (private const string):
  "session_user_id"       ← user.id dari response login (int → string)
  "session_user_name"     ← user.name dari response login
  "session_access_token"  ← Bearer token untuk request API
  "session_refresh_token" ← disimpan, untuk kegunaan lain nanti
  "session_expiry"        ← Unix timestamp (UtcNow + expires_in detik)


Public properties (read-only):
  static string UserId        → PlayerPrefs.GetString("session_user_id")
  static string UserName      → PlayerPrefs.GetString("session_user_name")
  static string AccessToken   → PlayerPrefs.GetString("session_access_token")
  static string RefreshToken  → PlayerPrefs.GetString("session_refresh_token")


Methods:
  SaveSession(userId, userName, accessToken, refreshToken, expiresInSeconds)
    → hitung expiry: DateTimeToUnix(UtcNow) + expiresInSeconds
    → simpan semua ke PlayerPrefs
    → PlayerPrefs.Save() untuk flush ke disk Android


  IsSessionValid()
    → cek HasKey("session_access_token") + HasKey("session_expiry")
    → parse expiry, bandingkan vs UtcNow
    → kalau expired: auto ClearSession(), return false
    → return true kalau valid


  ClearSession()
    → DeleteKey semua keys, PlayerPrefs.Save()
    → dipanggil saat logout atau session expired


  DateTimeToUnix(DateTime) [private]
    → (long)(dt - epoch).TotalSeconds


Catatan: expires_in dari server = 31536000 detik (1 tahun).
Expiry dihitung client-side dari UtcNow saat SaveSession dipanggil.
PlayerPrefs Android = plain text XML di app storage.
Jangan simpan password — hanya token server-generated.


----------------------------------------------------------------
  AuthManager.cs  [SELESAI & SIAP PAKAI — MonoBehaviour]
----------------------------------------------------------------
Attach ke GameObject AuthManager di LoginScene.
Handle form login, POST ke JTVHub, save session, redirect scene.


Inspector fields:
  [Header("Input Fields")]
    TMP_InputField emailLoginField      ← drag EmailField
    TMP_InputField passwordLoginField   ← drag PasswordField


  [Header("Feedback (Image GameObjects)")]
    GameObject warningImage   ← Image asset error (default inactive)
    GameObject confirmImage   ← Image asset loading/berhasil (default inactive)


  [Header("UI")]
    UnityEngine.UI.Button loginButton   ← drag BtnLogin


  [Header("Scene Target")]
    string sceneAfterLogin = "SelectMode"


Endpoint: https://hub.jtv.co.id/api/login


Response model (private, Serializable):
  LoginUser  { int id; string name; string email; }
  LoginResponse {
    LoginUser user;
    string access_token; string refresh_token;
    string token_type;   long expires_in;
  }


Flow Login():
  1. Trim email, ambil password dari TMP_InputField
  2. Validasi kosong → SetWarning(true) jika kosong
  3. SetWarning(false) → StartCoroutine(PostLogin())


Flow PostLogin() [Coroutine]:
  1. SetLoadingState(true) → disable button, tampil confirmImage
  2. Buat WWWForm dengan fields:
       email, password,
       device_uuid="67", device_name="yes",
       platform="Android", app_id="game_GolakGolek"
  3. UnityWebRequest.Post(LOGIN_URL, form)
     + header Accept: application/json
  4. Tunggu response
  5. SetLoadingState(false)
  6. Kalau gagal → SetWarning(true), Debug.LogWarning, yield break
  7. JsonUtility.FromJson<LoginResponse>(json)
  8. Kalau access_token null/empty → SetWarning(true), yield break
  9. SessionCache.SaveSession(user.id, user.name, access_token,
                              refresh_token, expires_in)
  10. SetConfirm(true) → WaitForSeconds(0.8f)
  11. SceneManager.LoadScene(sceneAfterLogin)


Helpers:
  SetLoadingState(bool loading)
    → loginButton.interactable = !loading
    → SetConfirm(loading)
  SetWarning(bool show) → warningImage.SetActive(show)
  SetConfirm(bool show) → confirmImage.SetActive(show)


Catatan:
  - WWWForm otomatis set Content-Type: x-www-form-urlencoded
  - Start() menyembunyikan kedua image di awal (SetActive false)
  - device_uuid="67" dan device_name="yes" sengaja hardcode
    untuk bypass Android device permission (SystemInfo tidak dipakai)

    → Debug.LogWarning kalau gagal parse

----------------------------------------------------------------
  GameModeController.cs  [MonoBehaviour — MainGameScene only]
----------------------------------------------------------------
Attach ke GameObject "GameModeController" di bawah Managers, MainGameScene.
TIDAK DontDestroyOnLoad.


Inspector fields:
  float timeAttackDuration = 180f   ← durasi TA dalam detik (3 menit default)
  int   targetItemCount    = 8      ← jumlah item untuk menang


Public state (read-only):
  GameMode CurrentMode
  float    TimeRemaining
  bool     IsGameOver
  bool     IsGameWon
  bool     IsTimerRunning


Events:
  Action<float> OnTimerTick        ← per frame, kirim sisa waktu (TA only)
  Action        OnTimerExpired     ← sekali saat waktu habis (TA only)
  Action        OnGameWin          ← semua target item terkumpul
  Action        OnGameLose         ← waktu habis di TA
  Action<int>   OnCartCountChanged ← setiap cart berubah, kirim count


Flow:
  Awake()  → baca GameSession.SelectedMode → set CurrentMode
  Start()  → subscribe CartSystem.OnCartChanged
           → kalau TA: StartCoroutine(TimerCoroutine())
  Timer    → yield return null (per frame) + Time.deltaTime
           → OnTimerTick?.Invoke(TimeRemaining)
           → kalau habis: TriggerGameLose()
  HandleCartChanged() → CheckWinCondition(cartCount)
           → kalau >= targetItemCount: TriggerGameWin()


Public helpers:
  float  GetElapsedTime()    → timeAttackDuration - TimeRemaining
  string GetModeString()     → "TimeAttack" | "Golek" (untuk POST)
  float  GetWaktuSelesai()   → elapsed time (TA) | 0f (Golek)


Catatan:
  Timer pakai per-frame coroutine (bukan WaitForSeconds) supaya
  TimeRemaining smooth dan bisa di-fire ke UIController tiap frame.
  Time.timeScale = 0f (pause) otomatis menghentikan Time.deltaTime
  sehingga timer ikut berhenti tanpa logika tambahan.

================================================================
  CATATAN TEKNIS PENTING
================================================================


1. JsonUtility tidak support:
     - Root-level JSON array → harus di-wrap dulu
     - Custom key mapping → harus pakai RemapJsonKeys() manual
     - [NonSerialized] fields di-skip otomatis ✓
     - Nested object HARUS semua class [System.Serializable]
       kalau tidak, nested object null setelah parse


2. Newtonsoft.Json tidak dipakai karena butuh explicit reference
   di .asmdef file. Tanpa itu compile error muncul meski package
   sudah ter-install. Solusi: pure string replacement di
   RemapJsonKeys() — zero dependency.


3. Field numerik dari API adalah JSON string, bukan JSON number.
   JsonUtility tidak bisa auto-convert → semua disimpan sebagai
   string dengan suffix Raw, di-parse manual pakai
   CultureInfo.InvariantCulture supaya desimal selalu "." bukan ","
   regardless locale device Android.


4. PlayerPrefs menyimpan plain text di Android.
   Jangan simpan password. Token server-generated = aman.


5. ShelfUnit.Start() jalan sebelum API fetch selesai (async).
   Fallback Inspector data bersifat sementara, di-override
   SetItemData() begitu ShelfManager selesai.


6. CartSystem dan APIManager pakai DontDestroyOnLoad → persist
   antar scene. Pastikan tidak ada duplicate instance saat
   scene reload.


7. Untuk icon inventory: tidak ada 2D asset tersedia.
   Solusi rencana: RuntimePreviewGenerator — render FBX ke
   RenderTexture 128×128 dengan preview camera + layer masking,
   convert ke Sprite, cache di IconRegistry.


8. urutan_rak range 0–79 (80 item, 1 item 1 rak). Pastikan tidak
   ada ShelfUnit di scene yang shelfId-nya dibiarkan default 0
   tanpa sengaja — bisa terjadi false match ke item rak pertama.


9. Backend POST belum bisa ditest. Format dikonfirmasi:
   json_decode(file_get_contents('php://input')) ✓
   Content-Type: application/json ✓


10. WWWForm di Unity otomatis set header:
    Content-Type: application/x-www-form-urlencoded
    Tidak perlu set manual. Dipakai AuthManager untuk POST login.


11. device_uuid dan device_name di AuthManager di-hardcode:
    device_uuid = "67", device_name = "yes"
    Alasan: bypass kebutuhan SystemInfo.deviceUniqueIdentifier
    yang memerlukan permission Android lebih dalam.
    Server menerima nilai ini tapi tidak kritis untuk game logic.


12. OnClick() di Unity Editor:
    Drag GAMEOBJECT dari Hierarchy ke slot object — bukan
    file .cs dari Project window. Kalau drag file script,
    dropdown function tidak muncul (hanya "string name").


13. Touch UI Android tidak respons — cek urutan ini:
    a. EventSystem ada di scene?
    b. Canvas Render Mode = Screen Space - Overlay?
    c. Canvas punya component Graphic Raycaster?
    d. RectTransform button cukup besar di resolusi device?
